# Naming conventions

- Business vocabulary comes from the specification and is used consistently in code,
  tests, API and documentation. One concept, one name.
- Java: standard conventions; no abbreviations for domain terms.
- REST: plural resources, kebab-case paths, no verbs in paths.
- Database: snake_case, singular table names or plural - pick one and enforce it here.
- Rule files, specs and plans: kebab-case file names, one topic per file.
