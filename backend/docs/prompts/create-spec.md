# Prompt - explore a business need and create the specification

We have a new business need: <describe the need in business vocabulary>.

Do not write any code. Explore the problem with me first:

1. Ask me the questions a product owner would have to answer.
2. List the affected domains, routes and data.
3. Propose 2-3 approaches with trade-offs.

Then create docs/superpowers/specs/NNN-<feature-name>.md following the structure in
docs/superpowers/specs/README.md, with explicit numbered invariants.
Stop after the specification. We run the security-review skill before any implementation.
