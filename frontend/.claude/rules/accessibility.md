# Accessibility rules

- WCAG 2.1 AA is the target for every screen.
- Semantic HTML first; ARIA only when semantics are not enough.
- Every interactive element: keyboard reachable, visible focus state, accessible name.
- Forms: labels bound to inputs, errors announced, not colour-alone.
- Contrast validated for text and UI components - run the checks, do not eyeball.
- Tables: proper headers and captions for data grids.
- Accessibility review is part of the feature loop (see CLAUDE.md workflow), not a final audit.
